## Введение

Datashield — система для автоматической анонимизации персональных данных в текстах на русском языке. Система идентифицирует и заменяет персональные данные, такие как имена, адреса, номера телефонов и другую чувствительную информацию.

Данное руководство предназначено для конечных пользователей системы и описывает способы использования функций анонимизации.

## Использование веб-интерфейса

Самый простой способ использования системы — через веб-интерфейс. Веб-версия доступна по адресу: [https://gitgud-site-3ajy.vercel.app/anonymize](https://gitgud-site-3ajy.vercel.app/anonymize)

### Пошаговая инструкция

1. **Доступ к системе**
   - Откройте любой веб-браузер
   - Перейдите по ссылке [https://gitgud-site-3ajy.vercel.app/anonymize](https://gitgud-site-3ajy.vercel.app/anonymize)

2. **Ввод данных**
   - В поле для ввода текста скопируйте или введите текст, требующий анонимизации
   - Размер текста не должен превышать 100 000 символов

3. **Запуск анонимизации**
   - Нажмите кнопку "Анонимизировать"
   - Дождитесь окончания обработки (время зависит от объема текста)

4. **Получение результата**
   - В поле результата отобразится анонимизированный текст
   - Все обнаруженные персональные данные будут заменены на синтетические аналоги

5. **Копирование результатов**
   - Используйте кнопку "Копировать" для сохранения результата в буфер обмена
   - Для повторной анонимизации просто замените текст во входном поле

### Пример анонимизации в веб-интерфейсе

**Исходный текст:**
```
Иванов Иван Иванович,
12.03.1990 г. Москва,
ул. Ленина, д. 10
Тел: +7 (999) 123-45-67
```

**Результат анонимизации:**

```
Петров Петр Петрович,

ул. Сталина, д. 15

```

## Использование локальной версии

Если вам требуется обработка большого количества текстов или недоступен интернет, вы можете использовать локальную версию системы.

### Требования

- Python 3.8 или выше
- Установленные зависимости из файла `requirements.txt`
- Распакованная модель из папки `model/`

### Запуск через Python

1. Установите все необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Используйте предоставленный скрипт для анонимизации:
   ```bash
   python text_raw_model_output.py
   ```
   
Подробная инструкция по установке и запуску локальной версии доступна в файле [launch_guide.md](launch_guide.md).

## Типы обнаруживаемых данных

Система Datashield обнаруживает и анонимизирует следующие типы персональной информации:

### Персональные данные
- **ФИО**: имена, фамилии, отчества
- **Даты**: даты рождения, паспортные даты
- **Возраст**: упоминание возраста человека

### Контактная информация
- **Телефоны**: мобильные, стационарные и международные номера
- **Email**: адреса электронной почты
- **Веб-адреса**: персональные URL, профили

### Адреса и локации
- **Адреса**: улицы, дома, квартиры
- **Города**: названия населенных пунктов
- **Географические объекты**: страны, регионы
- **Координаты**: геолокационные данные

### Документы и идентификаторы
- **Документы**: паспортные данные, ИНН
- **Финансы**: номера карт, счетов
- **Транспорт**: номера автомобилей
- **Цифровые**: IMEI, MAC-адреса

## Вопросы и ответы

### Насколько точна система?

Система использует современные алгоритмы машинного обучения и показывает точность до 91% на стандартных наборах данных. Однако стопроцентная точность не гарантируется, особенно для редких или необычных форматов данных.

### Безопасно ли использовать онлайн-сервис для конфиденциальных данных?

Онлайн-сервис работает без сохранения данных. Все обработки происходят в памяти и не записываются на серверы. Тем не менее, для особо чувствительных данных рекомендуется использовать локальную версию системы.

### Поддерживаются ли другие языки, кроме русского?

На данный момент система оптимизирована только для русского языка.

### Что делать, если система не обнаруживает некоторые персональные данные?

Если система пропускает определенные данные, попробуйте:
1. Проверьте формат данных на соответствие стандартным шаблонам
2. При локальном использовании увеличьте чувствительность системы
3. Убедитесь, что данные написаны на русском языке

### Можно ли интегрировать систему с другими программами?

Не реализовано. Планируется добавить.

### Есть ли ограничения по объему обрабатываемого текста?

Веб-интерфейс ограничен 100 000 символов на запрос. Локальная версия может обрабатывать тексты практически любого размера, но время обработки будет пропорционально увеличиваться.
