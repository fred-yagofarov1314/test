# Datashield

## О проекте

Datashield — это система для автоматической анонимизации персональных данных в текстах на русском языке. Система использует современные методы обработки естественного языка на основе нейронных сетей для распознавания и замены персональных данных в тексте.

## Возможности

- Автоматическое распознавание персональных данных в тексте
- Замена обнаруженных данных на синтетические или маркеры
- Сохранение структуры и смысла исходного текста
- Поддержка разных типов персональных данных:
  - ФИО (имена, фамилии, отчества)
  - Адреса и географические названия
  - Телефонные номера
  - Электронные адреса (email)
  - Даты
  - Идентификационные номера документов
  - и многие другие типы чувствительной информации

## Технологии

Система построена на основе глубоких нейронных сетей с использованием:
- PyTorch для работы с нейронными сетями
- Трансформеров BERT, адаптированных для русского языка
- Слоя LSTM для улучшения контекстного понимания
- Условных случайных полей (CRF) для улучшения качества предсказаний

## Зависимости

Для работы с системой необходимы:
```
torch>=1.8.0
transformers>=4.5.0
numpy>=1.20.0
sentencepiece>=0.1.96
pytorch-crf>=0.7.2
```

## Начало работы

1. Клонируйте репозиторий и перейдите в директорию проекта
2. Установите зависимости: `pip install -r requirements.txt`
3. Следуйте инструкциям в файле [launch_guide.md](launch_guide.md) для запуска системы

## Доступные компоненты

Клиентам доступны следующие компоненты:
- `test_raw_model_output.py` - скрипт для прямого взаимодействия с моделью
- `custom_model` - модуль с архитектурой нейронной сети
- `custom_utils` - вспомогательные функции для работы с моделью
- Папка `model` - предобученная модель для распознавания сущностей
- Веб-интерфейс по адресу [https://gitgud-site-3ajy.vercel.app](https://gitgud-site-3ajy.vercel.app)
