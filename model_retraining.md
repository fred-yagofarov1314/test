# Информация о переобучении модели Datashield

## Важное примечание

**Переобучение модели доступно только для команды разработчиков.**

Вам предоставляется предобученная модель, оптимизированная для распознавания и анонимизации персональных данных в русскоязычных текстах. Возможность самостоятельного переобучения модели не входит в стандартный пакет услуг.

## Доступные компоненты

В рамках стандартного доступа вам доступны:

1. **Предобученная модель** — оптимизированная для русского языка модель в папке `model/`
2. **Интерфейс API** — для взаимодействия с моделью через модули `custom_model` и `custom_utils`
3. **Веб-интерфейс** — для использования через браузер по ссылке [https://gitgud-site-3ajy.vercel.app/anonymize](https://gitgud-site-3ajy.vercel.app/anonymize)

## Получение обновлений модели

Команда GitGud регулярно выпускает обновления модели с улучшенной точностью и расширенным функционалом. При необходимости обновления модели обращайтесь к вашему менеджеру по продажам или через официальный канал поддержки.

Для получения информации о возможностях кастомизации и условиях предоставления этой услуги, пожалуйста, свяжитесь с представителем команды GitGud.
