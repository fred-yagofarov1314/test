## Архитектура системы

Datashield построена на основе современной архитектуры Named Entity Recognition (NER) с использованием глубоких нейронных сетей.

### Основные компоненты архитектуры:

1. **Предобученная языковая модель** — адаптированная для русского языка BERT-модель с дополнительным слоем для распознавания именованных сущностей
2. **Токенизатор** — компонент для разбиения текста на токены
3. **Модуль NER** — модуль распознавания именованных сущностей на основе BiLSTM-CRF (двунаправленная LSTM сеть с условным случайным полем)
4. **Модуль замены** — компонент, выполняющий замену обнаруженных персональных данных

### Схема работы системы:

```
Входной текст → Токенизация → NER (выявление сущностей) → Замена сущностей → Анонимизированный текст
```

## Компоненты системы

Система включает следующие компоненты:

### Доступные компоненты:

1. **model/** — папка с предобученной моделью
   - Файлы конфигурации модели и токенизатора
   - Веса модели для инференса
   - Словарь токенизатора

2. **custom_model/** — модуль для работы с моделью
   - Обертка модели для удобного использования
   - Функции для предобработки и постобработки данных

3. **custom_utils/** — вспомогательные утилиты
   - Функции для токенизации текста
   - Утилиты для работы с тегами BIO
   - Инструменты для обработки результатов распознавания

4. **text_raw_model_output.py** — скрипт для запуска анонимизации
   - Демонстрирует базовое использование модели
   - Поддерживает работу с текстом и файлами

5. **Веб-интерфейс** — доступен по адресу: [https://gitgud-site-3ajy.vercel.app/anonymize](https://gitgud-site-3ajy.vercel.app/anonymize)
   - Интерфейс для удобного использования системы онлайн
   - Обрабатывает тексты через API на сервере

## Процесс анонимизации

Процесс анонимизации текста состоит из следующих этапов:

### 1. Предобработка текста
- Разбиение на токены (слова, знаки препинания, числа)
- Нормализация регистра и формата
- Подготовка данных для подачи в модель

### 2. Распознавание сущностей (NER)
- Применение нейросетевой модели для идентификации персональных данных
- Классификация каждого токена с использованием BIO-разметки:
  - B (Beginning) — начало сущности
  - I (Inside) — продолжение сущности
  - O (Outside) — не является сущностью

### 3. Постобработка результатов
- Объединение последовательных токенов с одинаковым типом сущности
- Фильтрация результатов на основе порога уверенности
- Удаление дублирующих сущностей

### 4. Замена сущностей
- Генерация или выбор заменителей соответствующего типа
- Замена в исходном тексте с сохранением остальной информации

## Описание доступных модулей

### Модуль `model/`

Этот модуль содержит файлы предобученной нейросетевой модели для распознавания именованных сущностей (NER):

- **config.json** — конфигурация архитектуры модели
- **pytorch_model.bin** — веса обученной модели
- **tokenizer_config.json** — настройки токенизатора
- **special_tokens_map.json** — специальные токены
- **vocab.txt** — словарь токенизатора

### Модуль `custom_model/`

Модуль предоставляет высокоуровневый интерфейс для работы с моделью:

```python
from custom_model import AnonymizerModel

# Инициализация модели
model = AnonymizerModel(model_path="model/")

# Анонимизация текста
anonymized_text = model.anonymize_text("Иванов Иван Иванович живет в Москве")

# Получение детальной информации об обнаруженных сущностях
entities = model.extract_entities("Иванов Иван Иванович живет в Москве")
for entity in entities:
    print(f"{entity['type']}: {entity['text']} ({entity['start']}-{entity['end']})")
```

### Модуль `custom_utils/`

Содержит вспомогательные функции для обработки текста:

```python
from custom_utils import tokenize, bio_to_spans, replace_entities

# Токенизация текста
tokens = tokenize("Иванов Иван Иванович живет в Москве")

# Преобразование BIO-разметки в список сущностей
bio_tags = ['B-SURNAME', 'B-NAME', 'B-PATRONYMIC', 'O', 'O', 'B-CITY']
spans = bio_to_spans(tokens, bio_tags)

# Замена сущностей
replaced_text = replace_entities("Иванов Иван Иванович живет в Москве", spans, mode="random")
```

### Скрипт `text_raw_model_output.py`

Этот скрипт предоставляет интерфейс командной строки для анонимизации:

```bash
# Анонимизация текста
python text_raw_model_output.py
```

## Технические ограничения

1. **Производительность**: 
   - Скорость обработки: ~500-1000 токенов в секунду на CPU
   - ~5000-10000 токенов в секунду на GPU (зависит от устройства)

2. **Размер обрабатываемого текста**:
   - Максимальная длина одного документа: до 512 токенов в одном запросе
   - Для более длинных документов применяется разбиение на части

3. **Языки**:
   - Система оптимизирована только для русского языка
   - Поддержка других языков требует дополнительного обучения модели

4. **Точность распознавания**:
   - F1-мера: ~0.91 на стандартном тестовом наборе
   - Более низкая точность для редких форматов данных
